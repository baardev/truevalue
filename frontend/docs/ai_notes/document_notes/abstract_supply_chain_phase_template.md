# AI Note: Abstract Supply Chain Phase Template

## Document ID

abstract_supply_chain_phase_template

## One-Sentence Summary

Provides the reusable template for defining a physical supply-chain phase across materials and project instances.

## Key Claims

- A valid supply-chain phase must have a physical state, a transformation or custody change, and a measurable output.
- Phase mapping should preserve explicit links between metrics, units, sources, and custodians.
