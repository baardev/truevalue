# Preliminary Analysis

## Definition

Preliminary analysis is an early-stage assessment that identifies structure, gaps, hypotheses, and due-diligence questions without claiming final evidence or final scores.

## Why It Matters

The Blue Carbon project should remain preliminary until project-specific ecological, social, governance, market, and financial data are available.
