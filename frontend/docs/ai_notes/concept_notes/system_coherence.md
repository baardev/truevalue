# System Coherence

## Definition

The degree to which a system remains structurally stable because its constraints, outputs, custody relations, and feedback patterns remain aligned.

## Why It Matters

Clarity and N-D-C analysis use coherence as a primary signal before moving into value, price, or financial abstraction.
