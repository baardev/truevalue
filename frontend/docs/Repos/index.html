Repository tree (intra & extra)

Under docs/Repos the project keeps two kinds of material: intra (core, in-repo methodology, TVPCI, PDI, and game-theory work) and extra (outward-facing and partner-specific reports, briefs, and proposals). The same static files are also reachable from the MkDocs wiki where pages are included in the sidebar.

Repos / intra (core documentation)

Authoritative source files for the modeling stack: supply/value templates, TVPCI, and Tholonic theory. Paths are docs/Repos/intra/<area>/. Standalone HTML under intra/ is listed on intra/index.html.

  • PDI — Phase Discovery Instrument

    Abstract and instance phase templates, NDC reference, PDI protocol YAML, and worked examples (e.g. gold, municipal water). These ground the PDI form and the wiki’s PDI section.

    Abstract supply template Abstract value template Wiki (PDI in nav)
  • TVPCI — True Value Pricing Convergence Index

    Convergence index HTML/PDF, foundation derivation, intro and explainer notes, and the reports hub (same sources linked from the frontend Reports page).

    Reports & briefings index Convergence index (HTML) Foundation (HTML)
  • gametheory

    Tholonic N-D-C vs game theory and related PDFs, twistor comparison, and the interactive slider page used from Research.

    Interactive (sliders) Tholonic vs game theory (PDF) Twistor (Markdown)
