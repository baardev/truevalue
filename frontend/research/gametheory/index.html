System A — Standard Game Theory

Each player updates their cooperation probability based purely on personal payoff. If cooperating yielded positive payoff they become more likely to cooperate next round; if it was negative they defect more. No signal about the shared resource exists. This models classical reinforcement learning in a public goods game where the Nash-optimal strategy often drifts toward defection, collapsing the commons.

System B — Tholonic Learning

Identical payoff rules, but each player also receives a sustainability signal: when the shared resource is threatened (low R), cooperators get a bonus and defectors get a penalty proportional to λ. This models the Tholonic principle that Contribution to the parent context matters — not just individual payoff. When λ is high enough the system finds an N-state that is both individually stable and system-sustaining, demonstrating how Tholonic selection pressure resists tragedy-of-the-commons collapse.

Slider explanations

Each slider changes one part of the game dynamics. The model re-runs immediately so you can see how the parameter affects cooperation, shared resources, and the gap between Standard vs Tholonic behavior.

Rounds
Number of time steps the game runs. More rounds reveal long-term dynamics and stability.
Players
Population size participating in the public goods game. Larger groups can amplify commons effects.
Seed
Random number seed for reproducibility. Same seed + same settings gives the same simulation path.
Cooperation cost
Penalty paid by a cooperator each round. Higher cost makes cooperation harder to sustain.
Public benefit multiplier
How strongly total cooperation is converted into shared payoff. Higher values reward cooperative groups more.
Regen per cooperator
How much each cooperator helps regenerate the shared resource each round.
Decay per defector
How much each defector depletes the shared resource each round.
Initial resource
Starting level of the shared commons resource (R) at round 0.
Learning rate
Speed of adaptation in cooperation probability. Higher values cause faster but potentially noisier behavior changes.
Initial coop probability
Starting probability that each player cooperates before any learning happens.
Tholonic lambda (λ)
Strength of sustainability pressure in System B. At 0, Tholonic effects are disabled; higher λ increases resource-aware incentives.
