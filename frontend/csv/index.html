Data catalog

CSV, JSON & YAML inputs (source-of-truth)

This page links to CSV schema files, JSON processed outputs, and YAML PDI / configuration files used by the Supply Chain and Value Chain layers. Keeping these links here avoids overcrowding the homepages.

Authoritative CSV tabular data lives under data/{project}/schema/; many UIs load derived JSON from data/{project}/processed/. PDI and similar workflows use YAML under docs/PDI/ and frontend/project/…/data/. Each HTML badge is set to /viewable/<original-path-without-suffix>.html (from the data file link on the same row) so it always matches the output of scripts/all2html.py.
