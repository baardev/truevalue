About the φ (Proportional Coherence) Model

φ
= 1.61803398... = (1 + √5) / 2

The φ model asks: does value flow between phases in natural proportion? In a harmonically coherent supply chain, each phase's operational N-value should be approximately φ times the preceding phase's N-value — the same ratio that governs biological growth, Fibonacci sequences, and the geometry of living systems.

  • Configuration: inst=2, D=2, C=3
  • Child N (D+C = first Fibonacci sum) = 5 — the same value as C in the π model. This is the structural link between π and φ
  • Score 100 = ratio exactly equals φ (1.618)
  • Score <40 = ratio critically far from φ — value extraction or suppression
  • Unlike π (phase-local), φ is chain-global — a single phase cannot be evaluated alone
  • Gold finding: P5→P6 (Vaulting) collapses to 0.498× — the most severe φ failure in the chain, followed by a disproportionate recovery at P6→P7 (Exchange)
