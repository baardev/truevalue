Tholonic N-D-C Framework: Primary and Return Chain

TVPCI (D role): Primary Chain

The forward supply chain: ecosystem baseline through cherry/EVOO/almond production, harvest, processing, certification, and market distribution. Measures transparency, custody, and value capture across 8 phases. Chain balance: 86.3% (Good zone).

TVPCI-R (C role): Return Chain

The ecological return chain: waste streams returned to the ecosystem (alperujo to soil, cherry marc to compost, almond shells to biomass). Measures how observable and accountable each phase's ecological contribution is. Return score: 71.4% PROVISIONAL.

B_chain (N role): Holon Balance

The integrated system balance combining primary and return chains. Formula: B_chain = 100 * exp(-2 * |TVPCI - TVPCI_R| / max(TVPCI, TVPCI_R)). Delta_chain = TVPCI - TVPCI_R = 86.3 - 71.4 = +14.9 (primary exceeds return). B_chain: 83.0 PROVISIONAL.

Delta_chain = TVPCI - TVPCI_R = +14.9 points (primary chain is 14.9 points stronger than ecological return chain). This gap indicates that the Marina Alta ecosystem is extracting more value from its ecological capital than it is returning to it. The drip irrigation vs aquifer drawdown trade-off is the primary driver of this imbalance.

B_chain = 83.0 (Good zone: primary chain leads, but not critically imbalanced)
