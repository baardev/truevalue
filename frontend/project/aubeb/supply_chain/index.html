📚 Project Information

Supply Chain Phases

  • Phase 0: Pre-commercial degraded ecosystem
  • Phase 1: Custodial formalisation
  • Phase 2: Data extraction, baseline remote sensing
  • Phase 3: Specification, carbon quantification
  • Phase 4: Certification, verification and registration
  • Phase 5: Commercialisation outward
  • Phase 6: Capital return, Conservation Fund deployment
  • Phase 7: Restoration specification, CBEMR design
  • Phase 8: Community custodial co-management
  • Phase 9: Physical recovery, active regeneration
  • Phase 10: Verified restoration, sustained blue economy asset NEW

Environmental Metrics (Sarah Integration)

  • 💧 Hydrology and coastal ecosystem monitoring
  • ♻️ Restoration survival and maintenance loops
  • ⚡ MRV and field-operation energy requirements
  • 🌱 Phase 2 baseline remote sensing and field survey inputs
  • 🌍 Carbon stock, biodiversity, and livelihood baselines
  • 📋 Missing-data register from the AUBEB PDI

Data Sources

  • African Union Commission (programme documentation)
  • Global Underwater Diagnostics, ODIN dMRV
  • TrueValue Analytics PDI AUBEB v1 (2026-04-21)
  • World Mangrove Council (industry benchmarks)
  • Blue carbon registry and verification references
  • Mangrove restoration and MRV standards

Operating Principles (9 Rule Sets)

  • Separation of Concerns (physical → value → financial)
  • Phase-Based Modeling (everything maps to phases)
  • Data-First Discipline (no speculation, mark opacity)
  • Transparency Classification (high/medium/low)
  • Custody Awareness (mandate ≠ stewardship ≠ control)
  • Verification Data as Anchor (MRV = reconciliation target)
  • Schema-First Development (all insights tabulated)
  • Deferred Interpretation (map terrain befbaseline value)
  • Reproducibility & Auditability (traceable claims)
