What is TVPCI-R?

Every supply chain phase generates outputs beyond the finished product: alperujo (wet olive paste), vegetation water (alpechin), pruning biomass, packaging glass, flexibag residues, and consumer containers. These streams flow back to the parent system — the ecosystem, soil, atmosphere, and commons that enabled the chain. TVPCI-R scores how observable and accountable each phase's ecological return is, using the same three-role structure (N, D, C) as the primary custody chain.

Note on scope: The TVPCI (TrueValue Physical Custody Index) is a comprehensive framework encompassing living wage measurement, provenance integrity, custody transparency across all chain phases, and environmental accounting. The recycling/return chain analysis here represents one application of the TVPCI — the ecological return and waste valorisation dimension. It does not represent the full TVPCI. For the complete definition, see the TrueValue Analytics website front page.

The primary chain (TVPCI) defines what was extracted and claimed — it is the bounding, forward structure (role D at the chain level). The return chain (TVPCI-R) contributes that material back, closing the loop to the parent holon (a holon is any entity that is simultaneously a whole in itself and a part of a larger system — here each phase is a holon, and the full chain is also a holon within the broader food system and ecosystem). The balance between them produces an emergent negotiated state (B_chain, role N) measuring how equitably the chain balances extraction against return. Olive oil structural finding: Phase 2 (Milling) has the highest return accountability (alperujo recovery is well-established); Phase 1 (Harvesting) and Phase 5 (Packaging) are the weakest return phases.
