🏦 Silicon Valley Bank
Structural Failure Analysis

An 8-phase N-D-C structural analysis of Silicon Valley Bank using public FDIC Call Report data and SEC filings through Q4 2022. The model identifies the failure 18 months before the March 2023 bank run, from data that was publicly available throughout.

⚠️

The core finding for financial managers

Standard regulatory metrics (CET1 12%, CAMELS 2, no enforcement actions) showed SVB as a healthy, well-capitalized institution through Q4 2022. The N-D-C structural analysis shows Phase 3 (Interest Rate Risk) entered Breakdown in Q3 2021 and remained there for six consecutive quarters. The failure was structurally visible. It was not detected because standard frameworks do not evaluate cross-phase structural balance.
