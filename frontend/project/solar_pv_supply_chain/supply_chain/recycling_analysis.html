Tholonic N-D-C Framework: Primary and Return Chain

TVPCI (D role): Primary Chain

The forward supply chain: polysilicon production through installation and grid connection. Measures manufacturing concentration, custody, and value capture across 6 phases. Chain balance: 79.0% (Fair zone).

TVPCI-R (C role): Return Chain

The ecological return chain: end-of-life panel materials (glass, silicon, silver, aluminium frame), manufacturing scrap silicon, and packaging returned or recovered. Measures how observable and accountable each phase's material return is. Return score: 58.9% PROVISIONAL.

B_chain (N role): Holon Balance

The integrated system balance combining primary and return chains. Formula: B_chain = 100 * exp(-2 * |TVPCI - TVPCI_R| / max(TVPCI, TVPCI_R)). Delta_chain = TVPCI - TVPCI_R = 79.0 - 56.9 = +22.1 (primary exceeds return). B_chain: 57.2 PROVISIONAL.

Delta_chain = TVPCI - TVPCI_R = +22.1 points (primary chain is 22.1 points stronger than the ecological return chain). This is a wider gap than typical for agricultural or nature-based chains in this project's corpus, reflecting the immaturity of solar PV end-of-life infrastructure relative to a manufacturing sector that scaled extremely quickly. Under 10% of retired panels are formally recycled through mandated take-back or recycling infrastructure in most markets.

B_chain = 57.2 (Failure zone, below the 61.8% Stressed threshold: the return chain significantly lags the primary chain, driven by the global recycling infrastructure gap)

R_p = recycling/return score for each phase (0-100): how observable and accountable the phase's material return is. Zone thresholds: Coherent ≥80; Stressed 61.8-80; Failure 38.2-61.8; Breakdown below 38.2.

Reduces upstream silicon demand, indirectly easing Phase 0 and Phase 1 D-pressure. Manufacturing efficiency capital expenditure; potential IRA 45X eligibility if paired with domestic capacity qualification.
3 Phase 2 (Cell) Silver paste recovery programme extended industry-wide, given silver's high per-unit recovery value relative to processing cost. R_p 68 to 78 (+10). Directly improves the highest-value single material recovery stream in manufacturing. Private capital, self-financing given silver market price; potential premium marketing for verified-recovery modules.
4 Phase 0 (Polysilicon) Standardize closed-loop silicon tetrachloride reclamation across all polysilicon capacity, not only the most modern Siemens-process plants. R_p 70 to 80 (+10). Brings legacy capacity up to the standard already achieved by modern plants. Capital retrofit financing; could be linked to the same traceability verification infrastructure proposed for the Phase 0 Phase Intervention Worksheet.

All R_p scores and omega weights on this project are labelled PROVISIONAL. No phase-resolved LCA data is currently available for the global solar PV chain at the granularity this worksheet requires. Scores are reasoned synthetic baselines derived from IEA public sources and general industry recovery-technology literature. A dedicated field data collection programme, paired with mandated take-back reporting, is required to activate the financial abstraction (e) layer for the return chain specifically.
