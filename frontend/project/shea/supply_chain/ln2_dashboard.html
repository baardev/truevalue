📊 Data Note — Shea Transformation Phase Data (Best-Available in Project)

Shea is the richest chain in the project for ln(2) analysis — it has three verified monetary anchor points ($150/MT, $4,000/MT, $47,500/MT) from public sources (RONGEAD, Acorn/EP Carbon reports). The D and C structural values are still inferred, but the monetary multipliers are real.

The collection phase has no formal first-sale price mechanism — the $150/MT is a market reference, not a formal floor price. Processing costs (mainly firewood/fuel) are well-documented. Manufacturing margins are the most opaque — the $47,500/MT retail equivalent is estimated from reverse calculation of Cleo cosmetics retail pricing. Sources: RONGEAD 2019 shea value chain report; Acorn/EP Carbon shea project documentation; Kering Foundation True Price model.
