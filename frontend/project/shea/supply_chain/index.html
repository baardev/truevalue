📚 Project Information

Supply Chain Phases

  • Phase 0: Collection (Burkina Faso / West Africa) 3M women
  • Phase 1: First Sale / Aggregation
  • Phase 2: Trading / Bulking
  • Phase 3: Processing (nuts → butter) 100% renewable
  • Phase 4: Export BOTTLENECK
  • Phase 5: Manufacturing (butter → cosmetic)
  • Phase 6: Retail (Cleo) 11.875× uplift

Key Metrics & Findings

  • 💧 94% of collectors are women (Phase 0)
  • 🌳 BAU: 20 kg firewood per kg butter → deforestation
  • ♻️ Serious Shea: >95% CO₂e reduction vs BAU
  • 🍫 90% of exported shea goes to chocolate (C-concentration risk)
  • 🇪🇺 EU now requires clean-energy processing (D-institutional barrier)
  • 💰 €50B Sahel ingredients market potential by 2030

Operating Principles (Tholonic N-D-C)

  • Separation of Concerns (physical → value → financial)
  • D-natural vs D-institutional constraints distinguished
  • Phase-Based Modeling (everything maps to a phase)
  • Data-First Discipline (no speculation; mark opacity)
  • Transparency Classification (high / medium / low)
  • Custody Awareness (ownership ≠ custody ≠ control)
  • Five-Layer Coherence (π, φ, √2, ln(2), e models)
  • Deferred Interpretation (map terrain before value)
  • Reproducibility & Auditability (traceable claims)
