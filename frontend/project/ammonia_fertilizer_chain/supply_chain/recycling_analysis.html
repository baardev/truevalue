TVPCI-R: Ecological Return Chain

Ammonia and Nitrogen Fertilizer Chain: Ecological Return Analysis

TVPCI-R (True Value Pricing Convergence Index, Return): the nitrogen loss and recovery chain overlapping the primary custody chain, since applied nitrogen that is not recaptured or recycled is the same nitrogen that drives the Phase 5 biogeochemical-flows boundary transgression. Nitrous oxide capture, manure and organic nitrogen recycling, and struvite recovery from wastewater are the three circular pathways assessed. Tholonic N-D-C Framework: Primary and Return Chain

TVPCI (D role): Primary Chain

The forward industrial and agricultural chain: feedstock through Haber-Bosch synthesis, downstream conversion, distribution, field application, and environmental return. Measures transparency, custody, and physical balance across 6 phases. Chain balance: 82.6% (Good zone, masking a severe Phase 5 tail-end failure).

TVPCI-R (C role): Return Chain

The nitrogen loss and recovery chain: nitrous oxide abatement at nitric acid plants, manure and organic nitrogen substitution for synthetic input, and struvite recovery from municipal wastewater. Measures how observable and accountable each phase's nitrogen return or recovery is. Return score: 48.9 PROVISIONAL.

B_chain (N role): Holon Balance

The integrated system balance combining primary and return chains. Formula: B_chain = 100 * exp(-2 * |TVPCI - TVPCI_R| / max(TVPCI, TVPCI_R)). Delta_chain = TVPCI - TVPCI_R = 82.6 - 48.9 = +33.7 (primary chain far exceeds return). B_chain: 44.2 PROVISIONAL.

Delta_chain = TVPCI - TVPCI_R = +33.7 points (the primary production and application chain is 33.7 points stronger than the nitrogen recovery and recycling chain). This large gap is the return-chain expression of the same Phase 5 structural failure identified in the primary chain: the global nitrogen system is built to produce and apply nitrogen at scale, but has almost no matching infrastructure to recover or recycle the nitrogen that is lost. This is consistent with the C-type biogeochemical-flows Planetary Boundaries transgression described in this repo's Paper 19.

B_chain = 44.2 (Failure zone: return chain lags far behind the primary chain)

All R_p scores and omega weights on this project are labelled PROVISIONAL. No phase-resolved LCA data is currently available for the global ammonia and nitrogen fertilizer chain at this level of granularity. Scores are reasoned synthetic baselines derived from public sources including Nature Food ammonia and fertilizer papers, Erisman et al. (2008), and the green ammonia review literature. A dedicated field data collection programme, particularly for diffuse Phase 5 nitrogen loss, is required to activate the financial abstraction (e) layer and to calibrate these R_p scores against measured recovery data.
