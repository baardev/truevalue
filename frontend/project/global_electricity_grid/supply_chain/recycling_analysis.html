Tholonic N-D-C Framework: Primary and Return Chain

TVPCI (D role): Primary Chain

The forward supply chain: fuel and resource input through generation, transmission, balancing, distribution, end use, and retirement. Measures transparency, custody, and physical flow across 7 phases. BAU chain balance: 81.8% (Good zone).

TVPCI-R (C role): Return Chain

The ecological return chain: waste streams returned to, recovered from, or disposed of outside the grid system (combustion residuals, retired batteries, turbine blades, solar panels, transformer materials, consumer e-waste). Return score: 59.8 PROVISIONAL.

B_chain (N role): Holon Balance

The integrated system balance combining primary and return chains. Formula: B_chain = 100 * exp(-2 * |TVPCI - TVPCI_R| / max(TVPCI, TVPCI_R)). Delta_chain = TVPCI - TVPCI_R = 81.8 - 59.8 = +22.0 (primary exceeds return). B_chain: 58.4 PROVISIONAL, Failure zone.

Delta_chain = TVPCI - TVPCI_R = +22.0 points (the primary supply chain is 22.0 points stronger than the ecological return chain). This gap indicates that the global electricity grid is building and generating faster than it is closing the loop on its own physical byproducts, consistent with widely documented real-world gaps in wind turbine blade recycling, coal ash pond remediation, and consumer electronics recovery.

B_chain = 58.4 (Failure zone: return chain lags the primary chain by a material margin)

Per-Phase Ecological Return Scores (R_p): PROVISIONAL

R_p = recycling/return score for each phase (0-100): how observable and accountable the phase's ecological return is. Zone thresholds: Coherent at or above 80; Stressed 61.8-80; Failure 38.2-61.8; Breakdown below 38.2.

All R_p scores and omega weights on this project are labelled PROVISIONAL. No phase-resolved LCA data is currently available for the global electricity grid across all jurisdictions. Scores are reasoned synthetic baselines derived from public sources including IEA reporting, the UN Global E-waste Monitor, and widely documented ash pond and turbine blade disposal cases. A dedicated field data collection programme is required to activate the financial abstraction (e) layer for the return chain specifically.
