Tholonic N-D-C Framework: Primary and Return Chain

TVPCI (D role): Primary Chain

The forward supply chain: mining through mineral refining, cathode/anode material production, cell manufacturing, pack assembly, and deployment. Measures transparency, custody, and value capture across 6 phases. Chain balance: 81.5% (Good zone).

TVPCI-R (C role): Return Chain

The ecological return chain: mine tailings management, refining effluent, manufacturing scrap recovery, second-life grid storage repurposing, and end-of-life black mass recovery. Measures how observable and accountable each phase's circular return is. Return score: 54.9 PROVISIONAL.

B_chain (N role): Holon Balance

The integrated system balance combining primary and return chains. Formula: B_chain = 100 * exp(-2 * |TVPCI - TVPCI_R| / max(TVPCI, TVPCI_R)). Delta_chain = TVPCI - TVPCI_R = 81.5 - 54.9 = +26.6 (primary chain far exceeds return chain). B_chain: 52.1 PROVISIONAL (Failure zone).

Delta_chain = TVPCI - TVPCI_R = +26.6 points (primary chain is 26.6 points stronger than the ecological return chain). This gap indicates that the lithium battery chain is extracting and processing far more material value than it is currently returning through formal circular economy channels. The under-5% formal EV battery recycling rate (PROVISIONAL) is the primary driver of this imbalance.

B_chain = 52.1 (Failure zone: return chain lags well behind the primary chain)

All R_p scores and omega weights on this project are labelled PROVISIONAL. No phase-resolved LCA data is currently available for the global lithium battery chain. Scores are reasoned synthetic baselines derived from public sources including IEA reporting, industry disclosures, and general recycling industry practice. A dedicated field data collection programme, particularly for Phase 5 as the first-generation EV battery retirement wave arrives, is required to activate the financial abstraction (e) layer for the return chain.
