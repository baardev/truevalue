\subsection{Step 1: New CSV schemas (provisional
data)}\label{step-1-new-csv-schemas-provisional-data}

\textbf{\href{frontend/project/gold/data/schema/gold_recycling_phases.csv}{\texttt{frontend/project/gold/data/schema/gold\_recycling\_phases.csv}}}
(new file)

Columns: \texttt{phase\_id}, \texttt{phase\_name},
\texttt{primary\_waste\_streams}, \texttt{omega\_p},
\texttt{omega\_source}, \texttt{data\_status}

Eight rows (phases 0-7). Provisional \texttt{omega\_p} derived from: -
Foran 2005: GHG split (electricity 44\%, direct ops 13\%, land prep 6\%,
diesel 4\%) concentrates mass at phases 1-2 - Newmont 2024: cyanide
spills at phase 2, land reclaimed at phase 1, water recycled at phase 2
- Schematic distribution: phase 0=0.20, phase 1=0.25, phase 2=0.25,
phase 3=0.10, phase 4=0.08, phase 5=0.05, phase 6=0.05, phase 7=0.02 -
All rows \texttt{data\_status\ =\ PROVISIONAL}

\textbf{\href{frontend/project/gold/data/schema/gold_recycling_indicators.csv}{\texttt{frontend/project/gold/data/schema/gold\_recycling\_indicators.csv}}}
(new file)

Columns: \texttt{phase\_id}, \texttt{indicator\_id},
\texttt{indicator\_label}, \texttt{role}, \texttt{scoring\_rule},
\texttt{max\_points}, \texttt{waste\_stream}, \texttt{source\_hint}

Covers all eight phases; 4-7 indicators per phase organized by N/D/C
role. Derived from Section 4.3 of the updated TVPCI paper.

\subsection{Step 3: New page ---
recycling\_analysis.html}\label{step-3-new-page-recycling_analysis.html}

\textbf{\href{frontend/project/gold/supply_chain/recycling_analysis.html}{\texttt{frontend/project/gold/supply\_chain/recycling\_analysis.html}}}
(new file)

Sections in order:

\textbf{A. Header + concept panel} - Explains TVPCI\_R as the return leg
to the parent holon - Shows the role assignment: TVPCI=\(D\),
TVPCI\_R=\(C\), B\_chain=emergent \(N\) - Provisional data banner

\textbf{B. Chain-level summary panel (three KPI cards)} - TVPCI
(primary, from existing \texttt{gold\_supply\_chain\_ui.json}) -
TVPCI\_R (recycling aggregate, from \texttt{gold\_recycling\_ui.json}) -
B\_chain (computed inline:
\texttt{100\ *\ exp(-2\ *\ \textbar{}TVPCI\ -\ TVPCI\_R\textbar{}\ /\ max(TVPCI,\ TVPCI\_R))})
- Δ\_chain signed bar (positive = over-defining, red; near-zero =
balanced, green)

\textbf{C. Chain-level spider chart (SVG, pure JS)} - 8-spoke radar, one
spoke per phase, spoke length = R\_p score × ω\_p weight - Overlay:
primary TVPCI phase scores in a different color for comparison - Legend:
TVPCI (custody) vs TVPCI\_R (ecological)

\textbf{D. Per-phase recycling panels (8 collapsible cards)} Each card
shows: - Waste streams listed for that phase - Small 3-spoke SVG radar:
N\^{}R, D\^{}R, C\^{}R - B\^{}R\_p score and Δ\^{}R\_p = D\^{}R\_p -
C\^{}R\_p signed diagnostic - ω\_p weight displayed

\textbf{E. Interactive questionnaire worksheet} - Collapsible accordion
per phase - For each indicator: label, role badge (N/D/C), input (0 to
max\_points), running subtotal - Live-updates R\_p scores and re-draws
all charts as user adjusts inputs - ``Reset to provisional'' button
restores schematic values - Export section: shows computed TVPCI\_R and
B\_chain from worksheet entries

SVG radar implementation: pure JS canvas-free, drawn as
\texttt{\textless{}svg\textgreater{}} with
\texttt{\textless{}polygon\textgreater{}} elements using trigonometric
point calculation. No external library needed, consistent with rest of
codebase.

\subsection{Key constraints}\label{key-constraints}

\begin{itemize}
\tightlist
\item
  All recycling data marked \texttt{PROVISIONAL} with source citations
  (Foran 2005, Newmont 2024)
\item
  No external chart libraries introduced; SVG drawn inline via JS
  trigonometry
\item
  \texttt{omega\_p} weights sum to exactly 1.0
\item
  Δ\_chain and B\_chain computed client-side from loaded JSON, not
  hardcoded
\item
  Phase numbering follows existing repo convention (0=Geological
  Prospecting through 7=Exchange Registration)
\end{itemize}
