# Programming manual (`docnav/Repos/intra/TVPCI/`)

Executable scripts in this folder. Invocation details live in script headers; this file describes what each program is for.

## `tholonic_constants_original.py`

Small reference implementation of **recursive estimators** framed in N, D, C form for constants pi/4, phi, e, sqrt(2), and ln(2). When run as a program it prints one numeric result per constant type from `compute_tholonic_constant`.

**Depends on:** Python 3 only (stdlib).
