System A — Standard Game Theory

Each supply chain phase optimises its own D/C balance purely in response to local payoff. If tightening Definition (D) constraints improved phase-level returns, the phase increases D regardless of downstream impact. No signal from the shared chain exists. This mirrors classical reinforcement learning where the Nash-optimal strategy can cascade toward a tragedy-of-the-commons collapse — Vaulting (Phase 6, balance 65.5%) is the likely failure point that drags down the whole chain.

System B — Tholonic Learning

Identical payoff rules, but each phase also receives a system N-state signal: when overall chain integrity is threatened, phases that maintain balance get a bonus and imbalanced phases get a penalty proportional to λ. This models the Tholonic principle that Contribution to the parent context (the chain as a whole) matters — not just local D/C balance. When λ is sufficient the system converges to a coherent N-state, demonstrating how Tholonic selection pressure resists cascade failure at the Vaulting and Recycling bottlenecks.

Parameter explanations — Gold Supply Chain context

Each slider changes one aspect of how the 9 phases interact. Phases are seeded with real N-D-C balance data. The weakest phase (Phase 6: Vaulting, 65.5% balance) is particularly sensitive to cost and decay pressure.

Rounds (market cycles)
Number of simulated market cycles. More rounds reveal which phases stabilise or collapse under sustained pressure.
Seed
Random seed for reproducibility. Same seed + same settings gives the same simulation path every time.
D-constraint overhead
Cost a phase pays each round to maintain its Definition (D) constraints — regulatory, physical, permitting burden. Higher values stress all phases, especially those with high D (Mining D=270, Processing D=276).
Downstream N-state multiplier
How strongly a phase's balanced Contribution (C) amplifies the shared chain integrity signal. Higher values reward phases that actively generate positive N-state for downstream phases.
Regen per balanced phase
How much each in-balance phase restores overall chain integrity (N) each round. Models how a well-functioning phase (e.g., Refining, 95.1%) contributes to chain health.
Decay per imbalanced phase
How much each out-of-balance phase degrades chain integrity. Vaulting (65.5%) and Recycling (80%) are primary sources of decay in real data.
Initial chain integrity (N)
Starting system N-state. Default 0.74 reflects the normalised average N across all 9 phases (avg N ≈ 221 / max N ≈ 300). Lowering this simulates a supply chain already under stress.
Phase adaptation rate
Speed at which phases learn and adjust their balance behaviour. High values can cause instability; low values model slow institutional change.
Tholonic lambda (λ)
Strength of the system-wide N-state signal in System B. At λ=0, Tholonic effects are off (identical to A). Increasing λ progressively rewards phases for maintaining chain integrity rather than just local D/C balance.
