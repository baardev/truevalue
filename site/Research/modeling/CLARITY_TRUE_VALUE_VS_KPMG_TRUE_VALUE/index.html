    Clarity True Value Framework and KPMG True Value

    A Comparative Research Paper on Structural System Coherence and Monetized Externality Accounting

    Abstract

    This paper compares the Clarity True Value Framework, a tholonic N-D-C system for phase-based analysis of physical, lifecycle, and value systems, with the existing KPMG True Value methodology. KPMG True Value is a corporate impact measurement approach that identifies economic, social, and environmental externalities, monetizes them, and presents them through a common financial metric. The Clarity framework evaluates systems as recursive N-D-C structures: Negotiation (N), Definition (D), and Contribution (C). It maps supply chains, infrastructure systems, lifecycle maintenance, and value layers by phase, then evaluates whether constraints and contributions can sustain a coherent system state.

    The two frameworks are not substitutes. KPMG True Value is strongest when the analytical problem is corporate externality monetization, board-level decision support, investment appraisal, reporting, and exposure to future internalization of social and environmental costs. Clarity True Value is strongest when the analytical problem is structural system diagnosis: where a physical system breaks, where opacity sits, whether a supply chain or infrastructure chain can sustain itself, and how maintenance, stewardship, and resilience affect system viability before financial interpretation begins. KPMG translates impacts into money. Clarity identifies whether the system being monetized is structurally coherent enough to be trusted.

    The central finding is that KPMG True Value is better suited to mature corporate and investment contexts where impacts can be converted into financial terms, while Clarity True Value is better suited to complex adaptive systems, early-stage project design, broken infrastructure, resource chains, and sustainability systems where the primary question is not yet "what is the value?" but "what is the system, where does it fail, and can it maintain itself?" This distinction is especially important for investment time horizon. KPMG is more immediately useful for near-term disclosure, internalization risk, and decision cases. Clarity is more directly useful for long-duration profit quality, including 10, 20, or 30-year returns that depend on whether the underlying system keeps producing value without degrading. It is also important for ESG and sustainable-investment screening. KPMG can help investors translate environmental and social impacts into financial language, but Clarity can test whether environmental, social, governance, maintenance, and lifecycle prerequisites are strong enough for the investment plan to remain viable over time. It is also important for analytical scope: supply chains are only one application of N-D-C. The same logic can be applied to chemical, material, philosophical, social, legal, economic, political, institutional, ecological, and other processes wherever a coherent N-state emerges from definable D and C relationships.

    Keywords

    True Value, KPMG True Value, Clarity True Value, tholonic framework, N-D-C, externalities, monetization, process coherence, supply chains, lifecycle analysis, system maintenance, sustainability, infrastructure failure, impact measurement.

    1. Introduction

    "True value" has become an important phrase in sustainability, corporate reporting, and systems analysis because conventional financial accounting often fails to capture the full cost and benefit of economic activity. A company may report profit while producing environmental degradation, unpaid social burden, resource depletion, or public-system stress. Conversely, a project may create ecological or social value that is poorly represented in standard financial accounts.

    KPMG True Value responds to this gap by monetizing economic, social, and environmental externalities and comparing them with financial earnings. KPMG describes the methodology as a way to combine financial earnings data with monetized externality data and assess how externalities may affect earning capability and risk profiles in the future. Its three broad steps are to assess "true" earnings, understand future earnings at risk, and create corporate and societal value through better business cases. KPMG states that the approach can be applied to a product, a company's global operations, or an entire value chain, including suppliers and downstream product use.

    The Clarity True Value Framework, as used in this project, approaches "true value" differently. It begins with system structure rather than financial translation. It maps phases, custodians, constraints, measurable outputs, opacity, maintenance requirements, and system lifecycle functions. It evaluates each phase through N-D-C:

    • N, Negotiation: the coherent system state that emerges from D and C.
    • D, Definition: the constraints, specifications, boundaries, limits, and requirements that define what the system is.
    • C, Contribution: the flows, outputs, integrations, and external relationships that define what the system does.

    This paper compares the two approaches. It asks six questions:

    1. What does each framework measure?
    2. What are the strengths and weaknesses of each?
    3. What forms of decision-making does each support?
    4. Which contexts are best suited to each framework?
    5. How does each framework handle short-term versus long-term return quality?
    6. How does each framework support ESG and sustainable-investment scrutiny?
    7. Can they be combined into a stronger analytical sequence?

    The argument is straightforward: KPMG True Value is a powerful financial-language framework for externality valuation, while Clarity True Value is a system-language framework for structural coherence. KPMG is strongest after a system and its impacts can be reasonably bounded. Clarity is strongest before and during that bounding process, especially where physical flow, custody, maintenance, and opacity matter. That emphasis should not be mistaken for a limitation to supply chains. Supply chains are a useful proving ground because phases and custody can be observed, but the N-D-C grammar is more general: any process with constraints, contributions, and an emergent coherent state can be analyzed. For investors, this means KPMG helps price visible impacts into present decision-making, while Clarity helps judge whether the system can keep generating reliable returns across longer holding periods. This gives Clarity a particular role in ESG due diligence: it can test whether sustainability claims are embedded in the operating design of a project, rather than appearing only as monetized impacts or reporting categories after the fact.

    2. KPMG True Value: Summary of the Framework

    KPMG True Value emerged from KPMG's 2014 report A New Vision of Value: Connecting corporate and societal value creation. The report argues that businesses need a method to understand and quantify externalities and the likelihood that those externalities will affect earning capability and risk profile. KPMG describes True Value as a methodology that combines financial earnings data with monetized externality data and evaluates potential internalization risk.

    The core method can be summarized in three steps:

    1. Assess the company's "true" earnings by identifying and quantifying material externalities.
    2. Understand future earnings at risk by analyzing exposure to drivers of internalization.
    3. Create corporate and societal value by developing business cases that capture value creation opportunities and reduce risk.

    KPMG's framework classifies externalities as economic, social, or environmental, and as positive or negative. It then applies valuation factors to express impacts in a common financial metric. KPMG's later explanatory material describes this as a way to inspire productive conversations in boardrooms and management meetings, support investment decisions, improve reporting, and strengthen relationships with stakeholders.

    The typical visualization is the KPMG True Value Bridge. The bridge shows how financial earnings are adjusted upward or downward by monetized positive and negative impacts. It allows managers to compare diverse impacts using money as a common measure.

    This gives KPMG True Value a clear orientation:

    • It begins from the perspective of a company, product, project, or value chain.
    • It identifies material externalities.
    • It converts impacts into financial terms.
    • It evaluates future risk from internalization.
    • It supports corporate strategy, reporting, and investment decision-making.

    The framework's power comes from translation. Social and environmental impacts are translated into a language that executives, investors, and boards already understand.

    3. Clarity True Value: Summary of the Framework

    The Clarity True Value Framework, as used here, is a tholonic N-D-C system. It evaluates systems as phase-based, recursive structures rather than as a list of impacts awaiting monetization.

    Although many examples in this project are supply chains, the framework is not inherently limited to supply chains. N-D-C can apply to any process that can be described through constraints, contributions, and an emergent negotiated state. This includes chemical processes, material systems, philosophical argument structures, social systems, legal frameworks, economic systems, political systems, institutional governance, ecological systems, and community processes. A supply chain is therefore one implementation class of the wider N-D-C process model.

    The unit of analysis is not primarily the company. It is the system phase. A phase must have:

    • A physical or operational state.
    • A transformation or custody change.
    • A measurable output.
    • A custodian or controlling actor.
    • A source category and transparency level.

    Every phase is evaluated through N-D-C:

    • D measures the constraints, requirements, specifications, or limits.
    • C measures the output, flow, integration, or contribution.
    • N measures the negotiated system coherence that emerges from D and C.

    The framework separates analytical layers:

    1. Supply chain: physical flow, custody, constraints, measurable outputs.
    2. System lifecycle: planning, buildout, operation, maintenance, repair, adaptation, renewal.
    3. Value chain: prices, margins, income, revenue, funding, and other financial or value interpretations.
    4. Financial abstraction: leverage, paper claims, derivatives, claims on assets, and other financial overlays.

    This separation is critical. Clarity does not treat price or monetized value as the first analytical act. It first asks whether the system exists as a coherent, traceable, measurable phase map. If the physical system cannot be mapped, measured, maintained, or audited, then later valuation may be premature.

    Clarity also treats opacity as analytical data. If a phase lacks public information, has private custody, depends on commercial secrecy, or is physically inaccessible, it is marked as opaque. Missing data is not smoothed over. It is recorded as a finding.

    The framework is especially useful for:

    • Gold supply chains.
    • Shea butter community and agroforestry systems.
    • Blue economy and mangrove restoration programs.
    • Water recycling systems.
    • Broken municipal water infrastructure.
    • Electrical grid cascade failures.
    • Chemical, material, social, legal, economic, political, philosophical, and institutional processes where system coherence can be defined.

    In these cases, the central question is often structural: where is the system coherent, where does it lose balance, which phase fails, and what maintenance regime is needed to keep the system sustainable?

    4. Points of Similarity

    The two frameworks share several important commitments.

    First, both reject narrow financial accounting as sufficient. KPMG argues that financial results alone do not capture the full value that companies create or reduce for society. Clarity argues that value cannot be understood without physical flow, custody, constraints, maintenance, and measurable system outputs.

    Second, both frameworks try to support better decision-making. KPMG does this by bringing social and environmental impacts into boardroom language. Clarity does this by showing where the system is structurally coherent or structurally broken.

    Third, both frameworks can be applied beyond a single company, but not with the same breadth. KPMG states that True Value can be applied to products, global operations, or value chains. Clarity can be applied to commodity chains, infrastructure systems, ecosystems, community systems, lifecycle maintenance regimes, and more general processes such as legal, political, economic, social, material, chemical, and philosophical systems. KPMG expands across organizational and value-chain boundaries. Clarity expands across process types.

    Fourth, both frameworks are concerned with risk. KPMG focuses on the risk that externalities become internalized into future earnings. Clarity focuses on the risk that an N-state fails because D and C are imbalanced, a phase is opaque, or a maintenance function is missing.

    The shared ambition is to make hidden value and hidden risk visible.

    5. Key Differences

    The most important difference is the unit of analysis and the scope of application.

    KPMG True Value usually begins with a corporate entity, product, service, project, or value chain and asks how economic, social, and environmental impacts should be monetized. Clarity begins with system phases or process states and asks whether each phase has coherent D, C, and N properties. This makes Clarity a general process-coherence framework rather than only a supply-chain framework. Supply chains, legal systems, political systems, ecological systems, social systems, chemical transformations, and philosophical structures can all be examined when their constraints, contributions, and emergent N-state can be defined.

    The second difference is the treatment of money.

    KPMG uses money as the common metric. This is useful because it enables comparison across very different impacts. Clarity delays money until the value-chain layer. It treats physical coherence and maintenance as prior conditions for meaningful valuation.

    The third difference is the treatment of system maintenance.

    KPMG can include maintenance, resilience, or operating costs if they are material externalities or business risks. Clarity makes lifecycle maintenance a separate layer. It explicitly asks whether the sustainable system is itself sustainable. For example, a mangrove restoration project is not finished when trees are planted. It requires monitoring, adaptive management, replanting, community stewardship, and governance continuity.

    The fourth difference is the treatment of opacity.

    KPMG may work with internal company data and valuation factors, then present results through a bridge. Clarity requires each phase to carry a transparency classification. Low transparency is not necessarily treated as wrongdoing. It is treated as a structural feature that affects auditability.

    The fifth difference is time horizon.

    KPMG True Value is well suited to nearer-term corporate decision cycles because it converts impacts into a financial language that can be used in reporting, investment committees, risk reviews, and board presentations. It can address future earnings at risk, but it usually does so by translating externalities into financial exposure. Clarity True Value is better suited to long-duration return analysis because it asks whether the productive system can maintain coherence across time. A 10 or 20-year return is not only a function of today's externalities. It is also a function of maintenance discipline, custody continuity, lifecycle renewal, phase resilience, and whether D and C remain balanced as conditions change.

    The sixth difference is mathematical and conceptual framing.

    KPMG is grounded in externality accounting, valuation factors, risk internalization, and business decision support. Clarity is grounded in recursive N-D-C structure, phase boundaries, D-C balance, and emergent N-state coherence.

    The seventh difference is domain breadth.

    KPMG is powerful within the domain of monetized externality accounting and corporate financial decision support. Clarity is designed as a wider process grammar. If the analyst only compares the two frameworks through supply-chain examples, the comparison understates Clarity's spectrum of capabilities. A supply chain shows the method clearly, but it does not exhaust the method.

    The eighth difference is information preservation.

    KPMG's corporate materiality boundary is useful for management decisions, reporting, and investor communication, but it can also filter out adaptive-system data before that data becomes financially material. Natural, ecological, social, and infrastructure systems often contain weak signals, feedback loops, phase dependencies, maintenance requirements, and stewardship conditions that are real but not yet monetized. Clarity preserves more of this pre-financial system data by mapping the process first, before deciding which impacts are material to a company or convertible into financial terms.

    6. Strengths of KPMG True Value

    KPMG True Value has several major strengths.

    6.1 It speaks the language of corporate decision-making

    By monetizing externalities, KPMG True Value places environmental and social impacts into a metric that senior executives, investors, and boards already use. This reduces the translation gap between sustainability teams and financial decision-makers.

    6.2 It supports investment and strategy decisions

    KPMG explicitly positions True Value as a tool for investment decisions, product and service innovation, reporting, and risk reduction. This makes it practical for companies that need to decide where to allocate capital.

    6.3 It makes externalities visible

    Externalities are often treated as outside the company, outside the balance sheet, or outside the decision frame. KPMG True Value brings these impacts into the decision frame.

    6.4 It is scalable

    KPMG states that the method can be applied to a single product, a company, global operations, or an entire value chain. This makes it flexible for corporate use.

    6.5 It connects societal value and shareholder value

    The framework is designed to show how societal impacts may affect future revenues, costs, and risk profiles. This is useful in contexts where regulatory pressure, stakeholder expectations, resource scarcity, and market forces may internalize externalities.

    7. Weaknesses of KPMG True Value

    KPMG True Value also has limitations.

    7.1 Monetization can compress ethical complexity

    KPMG acknowledges that monetization is not exact and cannot fully express ethical aspects of externalities such as human rights, health, and safety. Some harms resist conversion into financial terms without loss of meaning.

    7.2 Valuation factors can create false precision

    Financial valuation of social and environmental impacts is often approximate. A bridge chart can look precise even when the underlying valuation is uncertain, contested, or context dependent.

    7.3 It may privilege the corporate viewpoint

    Academic critique of KPMG True Value argues that its framing can remain limited to a standardized commercial viewpoint and that stakeholder participation may be needed for a more pluralist conception of value and risk.

    7.4 It may obscure physical system failure

    If a broken infrastructure system or supply chain is immediately translated into money, the valuation may obscure where the physical system actually fails. A monetized cost of outage does not by itself show whether the failure occurred in fuel supply, winterization, dispatch, transmission, distribution, or emergency restoration.

    7.5 It may be strongest after boundaries are known

    KPMG True Value works best when material impacts can be identified and bounded. It is less suited to early-stage discovery where the system phases, custodians, opacity points, and maintenance functions are not yet known.

    7.6 It can understate long-term system decay

    KPMG can include future risk, but its primary strength is still the financial translation of identified impacts. This can make it less sensitive to slow structural degradation that has not yet become a monetized externality. For example, deferred maintenance, weakening governance, custody fragmentation, or declining community stewardship may not appear as a near-term financial impact even though they can reduce 10 or 20-year returns. In long-duration investments, the most important risk may be the system's gradual loss of coherence rather than a single visible externality.

    7.7 Corporate materiality boundaries can lose adaptive-system data

    Corporate materiality boundaries help organizations focus on the issues most relevant to their reporting, risk management, and capital allocation needs. The limitation is that adaptive systems do not always announce their risks through company-defined materiality categories. Feedback loops, ecological dependencies, informal stewardship, governance fragility, custody continuity, and maintenance obligations may be structurally important before they are visible as monetized externalities. If these signals are filtered out too early, the analysis can lose the nuanced relationships that explain whether the system can remain coherent over time.

    8. Strengths of Clarity True Value

    Clarity True Value has a different set of strengths.

    8.1 It maps the system before interpreting value

    Clarity insists that the system must be phase-mapped before value claims are made. This reduces premature financial interpretation and forces analysts to identify physical flow, custody, constraints, and measurable outputs.

    8.2 It identifies where systems break

    The N-D-C structure can show whether a system is D-heavy, C-weak, balanced, opaque, or unstable. This is especially useful for infrastructure failures, supply-chain bottlenecks, and lifecycle maintenance gaps.

    8.3 It separates physical, lifecycle, value, and financial layers

    This prevents category errors. A supply-chain phase is not the same as a profit margin. A maintenance failure is not the same as a price signal. A paper claim is not the same as physical custody.

    8.4 It treats maintenance as a first-class analytical layer

    Many sustainability systems fail because the system is built but not maintained. Clarity explicitly models this through lifecycle phases such as plan, build, operate, maintain, repair, adapt, and renew.

    8.5 It works in data-poor and opaque environments

    Clarity does not require every phase to be monetized. It can mark data as opaque, partial, inferred, public, private, or paywalled. Missing information remains visible.

    8.6 It can compare different system types

    The same N-D-C logic can be used for gold, shea butter, mangrove restoration, water recycling, municipal water failure, and electrical grid failure. This makes the method system-agnostic.

    8.7 It applies beyond supply chains

    Clarity can evaluate any process that has definable D, C, and N relationships. In a chemical process, D may describe reaction conditions, material limits, and required inputs, while C describes outputs, yields, and downstream interactions. In a legal process, D may describe statutes, jurisdiction, precedent, and procedural constraints, while C describes enforcement, rights, obligations, and social effects. In a political or social process, D may describe institutional rules and legitimacy boundaries, while C describes participation, coordination, and public outcomes. This gives Clarity a broader analytical spectrum than frameworks that are mainly designed for monetized corporate decision-making.

    8.8 It supports long-duration return quality

    Clarity is especially useful where profits depend on a system remaining productive over long periods. A mining chain, water system, agroforestry project, mangrove restoration program, or grid asset may look financially attractive in year one but weaken over time if maintenance, governance, custody, renewal, or phase balance is poor. By making lifecycle maintenance and D-C balance explicit, Clarity helps identify which systems are likely to keep producing value across 10, 20, or 30-year horizons. In this sense, it does not only ask whether a project has value now. It asks whether the source of that value can remain coherent enough to support durable returns.

    9. Weaknesses of Clarity True Value

    Clarity True Value also has limitations.

    9.1 It is less familiar to mainstream financial audiences

    N-D-C, tholonic recursion, and phase coherence are not standard boardroom language. The framework may require more explanation than monetized externality accounting.

    9.2 It may be harder to compare with conventional financial returns

    Because Clarity defers monetization, it may not immediately answer the question: what is the dollar value? This is a weakness in capital allocation contexts where decision-makers need financial comparison.

    9.3 Its scoring depends on phase design quality

    If phases are badly defined, N-D-C scores can be misleading. The method requires disciplined phase discovery and consistent schema design.

    9.4 It may require more upfront modeling work

    KPMG can begin from material impacts and valuation factors. Clarity often requires building a phase map, identifying custodians, separating layers, and documenting opacity before interpretation begins.

    9.5 It needs further external validation

    The framework is powerful internally, but to compete with established consulting and accounting frameworks, it needs peer review, case comparisons, public methodology notes, and reproducibility testing.

    10. Best-Use Contexts

    KPMG True Value is best suited for:

    • Corporate sustainability reporting.
    • Board and executive decision support.
    • Impact measurement for products and services.
    • Investment appraisal where social and environmental impacts should be expressed in financial terms.
    • Companies with access to internal data and a need to communicate with investors.
    • Mature value chains where impacts are known enough to monetize.
    • Scenario analysis around future internalization of externalities.
    • Nearer-term investment cases where the main need is to translate known impacts, risks, and opportunities into financial language.

    Clarity True Value is best suited for:

    • Supply-chain phase discovery.
    • Physical custody and flow analysis.
    • Infrastructure failure diagnosis.
    • Community and ecosystem projects where maintenance is central.
    • Early-stage project design before valuation.
    • Complex adaptive systems with many custodians, handoffs, or opacity points.
    • Broken systems such as Jackson water or ERCOT Uri.
    • General process analysis across chemical, material, social, legal, economic, political, philosophical, institutional, and ecological systems.
    • Systems where the key question is whether the system can sustain itself, not only what its monetized value is.
    • Long-duration capital allocation where 10, 20, or 30-year returns depend on maintenance, resilience, renewal, and structural coherence.

    In simple terms, KPMG is best when the system is sufficiently known and the task is to monetize impacts. Clarity is best when the system or process itself must be mapped, tested, and made coherent. KPMG is therefore more naturally aligned with short to medium-term financial communication. Clarity is more naturally aligned with long-term profit durability and broader process diagnosis, because it evaluates whether the value-producing system can survive the full investment horizon and whether the process itself is structurally coherent.

    11. Comparative Evaluation by Environment

    11.1 Corporate reporting

    KPMG has the advantage. It produces a financialized output that can be used in annual reports, sustainability reports, and investor-facing communication. Clarity can support the underlying system analysis, but KPMG is more directly aligned with corporate reporting conventions.

    11.2 Supply-chain redesign

    Clarity has the advantage. It can identify phase-level bottlenecks, custody breaks, opacity gaps, and maintenance weaknesses before financial interpretation. KPMG can then monetize the improvement case.

    11.3 Infrastructure failure

    Clarity has the advantage. In a case such as Jackson water or ERCOT Uri, the first task is to identify where the physical system failed. Monetizing the harm is useful, but only after the failure chain is mapped.

    11.4 Investor due diligence

    The best approach is combined. Clarity maps the system and identifies structural risk. KPMG monetizes externalities and future earnings at risk. Together they provide a stronger due-diligence package than either alone.

    11.5 Long-duration investment returns

    Clarity has the advantage when the investor's question is not only "what is this worth now?" but "will this system still be able to produce value in 10 or 20 years?" Long-term returns depend on maintenance, renewal cycles, governance continuity, bottleneck resilience, and whether constraints and contributions stay balanced. KPMG can help translate known impacts into current financial language, but Clarity is better positioned to identify the structural conditions that make long-term profit sustainable.

    11.6 General process analysis

    Clarity has the advantage when the object of analysis is not primarily a company, product, or value chain, but a process. This includes chemical, material, philosophical, social, legal, economic, political, institutional, and ecological processes. KPMG can still be useful if impacts later need to be monetized, but it does not provide the same general grammar for identifying how a process becomes coherent, where it becomes imbalanced, or how its N-state is maintained.

    11.7 Nature-based and community systems

    Clarity has an advantage at the design and maintenance stage because it can model stewardship, governance, monitoring, and adaptive management. KPMG has an advantage when impacts such as carbon sequestration, community benefits, and biodiversity outcomes need to be presented in financial terms.

    11.8 Mature corporate product analysis

    KPMG has the advantage. If a company already knows the product boundary and wants to compare externalities across options, monetization is practical and decision-friendly.

    11.9 Public-sector resilience planning

    Clarity has the advantage for diagnosis and planning because public systems often fail through maintenance gaps, fragmented custody, and underfunded lifecycle obligations. KPMG-style monetization can support cost-benefit analysis after those gaps are mapped.

    11.10 ESG and sustainable-investment prerequisite screening

    Clarity has an advantage where investors must determine whether a plan deserves capital before its impacts are monetized. This is an important distinction in ESG and sustainable-investment practice. KPMG True Value can translate environmental and social impacts into financial terms, which is useful for reporting, disclosure, risk communication, and investment committee presentation. However, that does not necessarily test whether the project itself has the lifecycle design, governance continuity, maintenance discipline, resource resilience, and stakeholder integration needed to remain sustainable.

    Clarity treats those conditions as prerequisites rather than later reporting variables. A project can therefore be screened for whether its environmental and social claims are structurally supported by the system that must deliver them. For some corporate investors, this may make Clarity the preferred front-end framework: it tests whether the investment plan is coherent, maintainable, and resilient before KPMG-style monetization turns known impacts into financial language.

    12. Toward an Integrated Method

    The frameworks can be integrated into a stronger sequence.

    Step 1: Use Clarity to map the physical system.

    Identify phases, custodians, transformations, measurable outputs, opacity, and source types.

    Step 2: Use Clarity to evaluate N-D-C coherence.

    Identify whether each phase has sufficient D, C, and N balance. Locate bottlenecks and lifecycle maintenance gaps.

    Step 3: Use Clarity to separate layers.

    Keep supply chain, lifecycle, value chain, and financial abstraction distinct.

    Step 4: Use Clarity to test long-term return durability.

    Evaluate whether the system can maintain its N-state over the investment horizon. Identify deferred maintenance, renewal gaps, phase brittleness, opacity, and D-C imbalance that could erode 10, 20, or 30-year returns.

    Step 5: Use Clarity to test ESG and sustainability prerequisites.

    Evaluate whether environmental, social, governance, maintenance, stewardship, and lifecycle assumptions are embedded in the operating structure of the plan. Identify whether sustainability claims are supported by phase-level responsibilities, measurable outputs, custody clarity, and renewal mechanisms.

    Step 6: Use KPMG True Value to monetize validated impacts.

    Once the system and impacts are bounded, monetize material externalities using appropriate valuation factors.

    Step 7: Use KPMG to evaluate future internalization risk.

    Assess whether externalities may become future costs, revenue risks, regulatory risks, or market risks.

    Step 8: Return to Clarity for system redesign.

    Use the N-D-C map to determine which phase or lifecycle intervention would improve coherence.

    This integrated sequence avoids two errors:

    • Monetizing a system before it is structurally understood.
    • Mapping a system without translating its impacts into decision-useful financial language when needed.

    13. Conclusion

    KPMG True Value and Clarity True Value answer different but complementary questions.

    KPMG True Value asks: what is the financial value of the company's positive and negative economic, social, and environmental impacts, and how might these affect future earnings?

    Clarity True Value asks: what is the system, what are its phases, where are the constraints and contributions, where is it opaque, where does it fail, and can it sustain itself?

    KPMG's framework is strongest in corporate contexts where monetization, investor communication, and strategic business cases are required. Clarity's framework is strongest in system design, infrastructure diagnosis, lifecycle maintenance, physical supply chains, general process analysis, and complex adaptive systems where valuation depends on first understanding the structure.

    The time-horizon distinction is central. KPMG is better suited to the financial translation of known impacts into current or near-term decision contexts. Clarity is better suited to assessing whether a system can preserve the source of value over long periods. For 10, 20, or 30-year returns, profit is not only a matter of present monetized impact. It depends on whether the system can keep operating, adapting, repairing, and renewing itself without losing coherence.

    The scope distinction is equally important. If Clarity is evaluated only through supply-chain case studies, its capabilities are artificially narrowed. The N-D-C model can be used wherever a process can be understood as a negotiation between definition and contribution. Supply chains are one visible use case, not the boundary of the framework. KPMG True Value is more domain-bound: it is strongest as a monetized externality and financial decision framework. Clarity is broader: it is a process-coherence framework that can be applied before, during, or after financial interpretation.

    The most defensible position is not that one framework replaces the other. The best use is sequential and complementary. Clarity should be used to map, test, and stabilize the system. KPMG should be used to monetize mature impacts and translate them into corporate and investment decisions.

    In that sense, Clarity True Value may be understood as a pre-monetization and systems-coherence engine, while KPMG True Value may be understood as a monetized externality and corporate decision engine. Together, they can support a more complete practice of true value: first map the terrain, then measure the value of moving through it.
